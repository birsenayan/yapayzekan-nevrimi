Yapay Zekânın Gelişim Evrimi

1. Projenin Amacı

Bu projenin amacı, yapay zekânın 1950'li yıllardan günümüze kadar geçirdiği tarihsel gelişimi incelemek ve önemli kilometre taşlarını grafiklerle göstermektir.

2. Proje Hakkında

Projede yapay zekâ alanındaki seçilmiş önemli gelişmeler yıllara göre incelenmiştir. Python programlama dili kullanılarak veriler okunmuş, düzenlenmiş, analiz edilmiş ve grafiklerle görselleştirilmiştir.

3. Kullanılan Teknolojiler

- Python
- Google Colab
- Pandas
- Matplotlib
- CSV ve JSON veri formatları
- GitHub

4. Veri Seti

Veri setinde yapay zekânın tarihsel gelişimindeki seçilmiş olaylar bulunmaktadır.

Veri sütunları:

- Yıl
- Gelişme adı
- Açıklama

Önemli not: Bu çalışma seçilmiş tarihsel örneklerden oluşan temsili bir eğitim projesidir. Yapay zekânın bütün gelişmelerini kapsamaz.

5. Proje Çıktıları

- Yapay zekâ tarihçesini içeren CSV dosyası
- JSON veri dosyası
- Yıllara göre gelişmeleri gösteren grafik
- Birikimli gelişimi gösteren grafik
- Python Colab notebook dosyası

6. Nasıl Çalıştırılır?

1. Google Colab açılır.
2. "Yapay_Zekanin_Gelisimi.ipynb" dosyası yüklenir.
3. Gerekli hücreler sırasıyla çalıştırılır.
4. Veri analizleri ve grafikler oluşturulur.
5. Sonuçlar CSV, JSON ve PNG formatlarında kaydedilir.
